To use Claude 4.5 Haiku for game balancing, you must explicitly request access to it in Amazon Bedrock.

### Steps

1. Go to the **AWS Console**, search for **Amazon Bedrock**, and select it.
2. In the left navigation pane, select **Model catalog**.
3. Select the AI model you want to use (e.g., **Anthropic Claude 4.5 Haiku**).
4. A window titled "Submit use case details" will pop up. Click **Submit use case details**.

   ![Submit Use Case 1](/images/aws_project/c%E1%BA%A5p%20quy%E1%BB%81n%20model%20AI.png)

5. Fill in the required information (Company name, Website URL, Industry, Intended users, Use cases) and click **Submit use case details** again to confirm.

   ![Submit Use Case 2](/images/aws_project/c%E1%BA%A5p%20quy%E1%BB%81n%20model%20AI(1).png)

6. On the model's page, click **Open in playground** to open the chat window.
7. Send any chat message to initialize and trigger the AI model for the first time.

   ![Activate Model](/images/aws_project/Bedrock-AI-g%E1%BB%ADi%20tin%20nh%E1%BA%AFn%20%C4%91%E1%BA%A7u%20ti%C3%AAn%20%C4%91%E1%BB%83%20k%C3%ADch%20ho%E1%BA%A1t%20model%20AI%20trong%20Bedrock.png)
