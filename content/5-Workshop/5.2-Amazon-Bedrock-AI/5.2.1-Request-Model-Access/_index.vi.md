Để sử dụng Claude 4.5 Haiku cho việc cân bằng game, bạn phải chủ động xin quyền truy cập trong Amazon Bedrock.

### Các bước thực hiện

1. Truy cập **AWS Console**, tìm kiếm **Amazon Bedrock**.
2. Trên thanh menu bên trái, chọn **Model catalog**.
3. Chọn model bạn muốn sử dụng (ví dụ: **Anthropic Claude 4.5 Haiku**).
4. Cửa sổ "Submit use case details" sẽ hiện ra. Nhấn nút **Submit use case details**.

   ![Submit Use Case 1](/images/aws_project/c%E1%BA%A5p%20quy%E1%BB%81n%20model%20AI.png)

5. Điền đầy đủ thông tin vào các trường (Company name, Website URL, Industry, Intended users, Use cases) rồi tiếp tục nhấn **Submit use case details**.

   ![Submit Use Case 2](/images/aws_project/c%E1%BA%A5p%20quy%E1%BB%81n%20model%20AI(1).png)

6. Ngay tại trang thông tin của model, nhấn **Open in playground** để mở cửa sổ Chat với AI.
7. Nhắn 1 câu bất kỳ (ví dụ: "Hello") để khởi chạy và kích hoạt model lần đầu.

   ![Activate Model](/images/aws_project/Bedrock-AI-g%E1%BB%ADi%20tin%20nh%E1%BA%AFn%20%C4%91%E1%BA%A7u%20ti%C3%AAn%20%C4%91%E1%BB%83%20k%C3%ADch%20ho%E1%BA%A1t%20model%20AI%20trong%20Bedrock.png)
