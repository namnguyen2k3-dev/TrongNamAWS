Amazon S3 will be used to host the JSON configuration files generated by AI so that the Unity client can download them directly without straining the API Gateway.

### Steps

1. Go to the **AWS Console**, search for **S3**, and select **Create bucket**.

2. In the **Create bucket** page, fill in the following:
   - **Bucket name**: Enter `cloud-game-cms-2026` (or a globally unique name).
   - **AWS Region**: Select `ap-southeast-1` (Singapore).

   ![Create S3 Bucket 1](/images/aws_project/s3-create-bucket(1).png)

3. Under **Object Ownership**, leave ACLs disabled (recommended). Uncheck **Block all public access** if you plan to make the JSON files publicly readable (though we will handle this via policy later). Acknowledge the warning and click **Create bucket**.

   ![Create S3 Bucket 2](/images/aws_project/s3-create-bucket(2).png)
