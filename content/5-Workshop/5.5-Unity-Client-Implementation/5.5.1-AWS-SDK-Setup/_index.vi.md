Để Unity có thể giao tiếp trực tiếp với AWS (nếu không dùng qua API Gateway), chúng ta có thể cài đặt AWS SDK for .NET vào project.

### Các bước thực hiện

1. Trong Unity, mở **Package Manager**.
2. Hoặc tải các file thư viện DLL của AWS SDK for .NET và kéo thả trực tiếp vào thư mục `Assets/Plugins`.
