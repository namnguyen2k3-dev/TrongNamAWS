To allow Unity to interact directly with AWS (if we use direct API instead of API Gateway), we can install the AWS SDK for .NET.

### Steps

1. In Unity, open the **Package Manager**.
2. Alternatively, download the AWS SDK for .NET DLLs and drag them into your `Assets/Plugins` folder.
