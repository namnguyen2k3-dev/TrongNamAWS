# Hands-on Workshop: Serverless AI Backend

In this workshop, we will build a Serverless AI game backend step-by-step.

You will configure **Amazon S3** for storage, set up **IAM permissions**, deploy an **AWS Lambda** function written in C#, integrate it with **Amazon Bedrock**, and connect it to the **Unity** engine.
